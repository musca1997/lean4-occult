# 来源与未核查内容（sources）

本文件的作用是**明确边界**：哪些内容是本项目自己的定义，哪些内容属于
传统说法但**尚未核查**。本文件不含任何引文；在完成原文核对之前，本项目
不引用具体文献的页码或字句。

## 1. 属于本项目的定义（无需外部来源）

以下内容完全由代码定义，正确性由 Lean 证明，与任何文献无关：

* `YinYang` 的两个构造子与对合 `neg`。
* `WuXing` 的五个构造子，以及 `next`、`overcomes` 两个**选定**的循环方向。
* `TianGan`、`DiZhi` 的构造子、索引顺序、`toFin`/`ofFin` 编码。
* 阴阳 = 序号奇偶的编码约定（`YinYang.ofParity`）。
* `JiaZi` 的“同阴阳”约束、索引与 `crt` 公式。
* `next` 的 60 周期、最小正周期 60、同阴阳配对与 `Fin 60` 的双射。

这些都是**定义 + 定理**，不是对传统体系的断言。

## 2. 通常被归为传统说法、但本项目**未核查**的内容

以下说法在常识层面广泛流传，本项目**没有**核对原文，也**没有**在代码中断言
其真伪。列出它们只是为了说明范围：

* 天干、地支与阴阳的具体对应（本库采用奇偶约定，见 `conventions.md`；
  这与常见说法一致与否，未做文献核对）。
* 五行相生、相克的次序（本库把“木→火→土→金→水→木”与
  “木克土、土克水、水克火、火克金、金克木”作为**定义**；
  传统文献中的表述差异未核查）。
* 天干与五行、地支与五行/生肖/方位的对应。
* 地支藏干、十神、旺衰、刑冲合害。
* 六十甲子与历法纪年、纪日、纪月的实际对应关系。
* 纳音、紫微斗数、四柱排盘、择日等任何术数应用。

## 3. 因此本库**不**声称

* 不声称任何术数体系“有效”或“科学”。
* 不声称上述传统说法有统一版本。
* 不声称索引 0 = 甲子对应某个具体历史日期（本库没有历法/时区/天文模型）。

## 4. 若要补充文献

若后续要引用具体文献，应满足：

1. 给出可核查的版本信息（作者、书名、卷次、出版社/影印本、页码）。
2. 逐条对应到代码中的定义或定理，并在本文件登记。
3. 若文献说法与代码约定不同，**修改代码或明确标注差异**，不得含糊处理。

在此之前，本文件保持“无引文”状态。
