# 来源与未核查内容（sources）

本文件区分三类东西：

1. **本项目的定义/约定**：由代码选定，正确性由 Lean 证明，不依赖文献；
2. **来源支持的有限规则**：逐条登记版本、段落定位、URL、访问日期与短引文；
3. **通常被归为传统说法、但本项目未核查的内容**：只说明范围，不作断言。

v0.1/v0.2 不含任何文献引文。v0.3 开始，只对能够公开核查的**有限安星规则**
登记短引文；这些引文只支持“某版本这样写”，不支持任何经验有效性主张。

## 1. 属于本项目的定义（无需外部来源）

以下内容完全由代码定义，正确性由 Lean 证明，与任何文献无关：

* `YinYang` 的两个构造子与对合 `neg`。
* `WuXing` 的五个构造子，以及 `next`、`overcomes`、`prev`、`overcomeBy` 四个
  **选定**的映射方向。
* `TianGan.wuXing` 与 `DiZhi.wuXing`（本气）两张映射表：它们只是项目选定的编码；
  本库不据此断言传统说法。`DiZhi.wuXing` **只是单一本气，不是藏干**。
* `ZiWei.Position`（`Fin 12`）上的对宫偏移 6、三合偏移 4/8、三方四正
  `{p, p+4, p+6, p+8}`：这些是位置组合的定义与定理。
* `ZiWei.Palace` 的宫名顺序与偏移（命 0、兄弟 1、…、父母 11）：这是**项目约定**，
  本库不声称它是唯一版本。
* `TianGan`、`DiZhi` 的构造子、索引顺序、`toFin`/`ofFin` 编码。
* 阴阳 = 序号奇偶的编码约定（`YinYang.ofParity`）。
* `JiaZi` 的“同阴阳”约束、索引与 `crt` 公式。
* `next` 的 60 周期、最小正周期 60、同阴阳配对与 `Fin 60` 的双射。
* v0.3 的 `ZiWei.Branch.ofDiZhi`：把十二支按 `DiZhi.toNat` 映射到位置
  子 0、丑 1、…、亥 11。这是**项目约定**，不是来源文字的一部分。
* v0.3 的“前 = +1、后 = −1”数值方向：方向本身由来源例子支持（见 §5），
  但把它写成 `Fin 12` 上的 `rotate 1` / `rotate (-1)` 是本项目的编码选择。

这些都是**定义 + 定理**，不是对传统体系的断言。

## 2. 通常被归为传统说法、但本项目**未核查**的内容

以下说法在常识层面广泛流传，本项目**没有**核对原文，也**没有**在代码中断言
其真伪。列出它们只是为了说明范围：

* 天干、地支与阴阳的具体对应（本库采用奇偶约定，见 `conventions.md`）。
* 五行相生、相克的次序（本库把它们作为**定义**）。
* 天干与五行、地支与五行/生肖/方位的对应：本库把 `TianGan.wuXing`、
  `DiZhi.wuXing`（本气）作为**定义**，与任何文献版本是否一致**未核查**。
* 地支藏干（一个地支对应多个天干，含中气、余气）：**明确不在本库范围内**。
* 十神、旺衰、刑冲合害。
* 紫微斗数的星曜吉凶、四化、限运、大限流年，以及“命宫位置如何由出生时间
  决定”：**明确不在本库范围内**。v0.3 只做“给定生年干/支后，四颗小星落在
  十二支宫位中的哪一位”。
* 六十甲子与历法纪年、纪日、纪月的实际对应关系。
* 纳音、四柱排盘、择日等任何术数应用。
* 除 §5 明确登记的三条安星规则之外，其他所有紫微斗数安星规则。

## 3. 因此本库**不**声称

* 不声称任何术数体系“有效”或“科学”。
* 不声称上述传统说法有统一版本。
* 不声称索引 0 = 甲子对应某个具体历史日期（本库没有历法/时区/天文模型）。
* 不声称 v0.3 的四颗星在任何流派、任何版本中都只有这一种安法。

## 4. 引用原则

若后续要引用具体文献，应满足：

1. 给出可核查的版本信息（作者、书名、卷次、出版社/影印本、页码；网页则给
   稳定 URL、修订号/访问日期与章节定位）。
2. 逐条对应到代码中的定义或定理，并在本文件登记。
3. 若文献说法与代码约定不同，**修改代码或明确标注差异**，不得含糊处理。
4. 不把同一文本的多个转载/翻印当成多个独立佐证；只有不同版本、不同文本传统
   才能作为独立见证。
5. 只摘录支持该条规则所需的短句；公版古籍可引用，但仍需注明出处与定位。

### 5.3 文本读法的明确说明

1. **“丙戊巳”**：来源把“丙、戊”并列写在“巳”前。本库读作
   `luCun 丙 = 巳`、`luCun 戊 = 巳`；这使 10 个天干落到 8 个位置。
   若读作“丙在戊巳”之类的其他断句，表会不同；本库不声称其他读法错误。
2. **“丁己禄存停午方”**：读作 `丁、己` 均在午。
3. **“寅午戍”**：来源写作“戍”，按三合组“寅午戌”读作“戌”。这是一处
   明显的形近讹字/异体，但本库保留原文并在此说明。
4. **“前/后”**：不采用现代地图方向，也不采用“顺/逆时针”的额外解释；
   只采用来源例子给出的数值关系：癸禄在子 → 丑为擎羊（+1）、亥为陀罗（−1）。
5. **天马**：只实现“生年支”天马；不实现流年天马、月马或其它变体。

### 5.4 来源可靠性、版本与派别范围

* **可靠性**：来源 A 是可公开访问、可固定修订号的转录文本；来源 B 是公版
  明刊本扫描件，叶面可核对。两者足以支持“这些规则见于《紫微斗數全書》
  卷二”的有限主张。但 A 未注明底本、非校勘本，B 的 OCR 不可靠；因此
  本库**不**声称已完成版本校勘，也不声称这些字句在所有版本中完全相同。
* **派别范围**：只覆盖《紫微斗數全書》书系的安星诀。紫微斗数另有《紫微斗數
  全集》《紫微斗數捷覽》以及《正統道藏》本等传统，规则与星名可能不同；
  本库不把它们混为一谈。
* **同名不同规则**：
  * 禄存：本库只做“生年干禄存”，不做流年流禄。
  * 擎羊、陀罗：本库只做随生年禄存的安法，不做流年流羊/流陀。
  * 天马：本库只做“生年支天马”，不做流年天马、月马。
  * 天魁、天钺：**不实现**。来源 A 的对应歌诀存在“壬癸免蛇藏”（“免”疑为
    “兔”）、“丙丁猪狗位”（“狗”与常见版本的“鸡”不同）等文本问题，且
    歌诀本身没有说明每组两个位置中哪个是魁、哪个是钺；不同版本/流派的
    配对也不同。强行实现会把文本问题伪装成确定规则。
  * 红鸾、天喜：**不实现**。其规则虽也只依赖年支，但本版本次范围只登记
    禄存、擎羊、陀罗、天马四条；不把“未实现”写成“已核查”。
* **方向/索引映射**：来源只用十二支宫位名，不给 0–11 的数字。数字映射是
  本项目约定；改变映射会改变 CLI 的数字输出，但不改变地支名输出。所有
  与来源对照的定理都同时给出地支表（`luCun_toDiZhi` 等），以免只依赖数字。
